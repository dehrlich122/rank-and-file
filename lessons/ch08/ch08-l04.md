# Gathering

A list can start empty, `[]`, and grow. `.append()` adds one item to the end of the list it is called on:

```python run
found = []
found.append(4)
print(found)
found.append(-1)
print(found)
found.append(7)
print(found)
```

`.append()` changes the list itself and hands nothing back. Keep what it hands back, and the list is lost:

```python run error
found = []
found = found.append(4)
found.append(-1)
```

A loop can do the gathering: each lap appends one more item. Then the finished list is there to use:

```python run
steps = []
for i in range(3):
    steps.append(1)
    print(steps)
for step in steps:
    knight.jump(2, step)
```

A list handed to a function is the same list, not a copy: what the function appends, the caller sees too.
