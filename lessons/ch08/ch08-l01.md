# A list of jumps

A **list** holds several values in a row, under one name. Write it with square brackets, the items separated by commas. Each item has a place, counted from 0, and `len()` says how many items there are:

```python run
route = [1, -1, 1]
print(route)
print(route[0], len(route))
```

You have held a list before: `split()` hands one back. Asking for a place past the end is an error:

```python run error
route = [1, -1, 1]
print(route[3])
```

A `for` loop over a list gives its name one item per lap, however long the list is, so the code never has to count. Here the examiner hands a list to a function, and the knight rides it:

```python run calls cross([1, -1])
def cross(steps):
    for step in steps:
        knight.jump(2, step)
```
