# In order

`sorted()` hands back a new list with the items in order, smallest first. The list it was given stays as it was. `min()` and `max()` hand back the smallest and the largest item, and `sum()` adds them all up. Pairs sort too, by their first item:

```python run
tolls = [30, 4, 18]
print(sorted(tolls))
print(tolls)
print(min(tolls), max(tolls), sum(tolls))
print(sorted([(2, 1), (0, 3), (1, 5)]))
```

Some keys carry a number instead of a name. The satchel holds them in the order they were picked up:

```python run
knight.jump(1, 2)
knight.pick_up()
knight.jump(1, -2)
knight.pick_up()
print(knight.inventory, max(knight.inventory))
```

An empty list has no largest item, so asking for it is an error:

```python run error
print(max(knight.inventory))
```
