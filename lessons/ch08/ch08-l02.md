# Pairs

A **tuple** is a few values that travel together, written with round brackets. A place on the board is one: an (x, y) pair. Take an item by its place, or **unpack** the pair into two names at once. `knight.position` is the pair your knight stands on:

```python run
place = (3, 1)
x, y = place
print(place[0], x, y)
knight.jump(1, 2)
print(knight.position)
```

A tuple can't be changed once it is made:

```python run error
place = (3, 1)
place[0] = 4
```

A list can hold pairs, and a `for` with two names unpacks each one as it comes:

```python run
jumps = [(1, 2), (2, -1), (-2, -1)]
for dx, dy in jumps:
    knight.jump(dx, dy)
print(knight.position)
```

A function can hand back two values the same way: `return x, y` makes a pair.
