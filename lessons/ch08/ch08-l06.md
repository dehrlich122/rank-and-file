# The examiner's last round

Nothing new here: everything in this chapter, in one spell. A list holds a row of values, and a `for` walks it. A pair unpacks into two names. `.append()` grows a list, the satchel fills as your knight picks up, and `sorted()` hands back a new list in order.

```python run calls tour([(1, 2), (2, -1)])
def tour(jumps):
    seen = []
    for dx, dy in jumps:
        knight.jump(dx, dy)
        seen.append(knight.position)
    return sorted(seen)
```
