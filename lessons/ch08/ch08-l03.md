# The satchel

Your knight carries a satchel: `knight.inventory`, a list the game fills. `knight.pick_up()` takes the key lying on the knight's stone and puts its name in. `in` asks whether a list holds something, and answers `True` or `False`. A door opens only to a knight carrying its key. Here the knight fetches the brass key, out and back, then takes the door:

```python run
print(knight.inventory)
knight.jump(1, 2)
knight.pick_up()
print(knight.inventory, len(knight.inventory))
print("brass" in knight.inventory, "iron" in knight.inventory)
knight.jump(-1, -2)
knight.jump(2, 1)
```

Without its key, a door stays shut:

```python run error
knight.jump(2, 1)
```

And there has to be a key to pick up:

```python run error
knight.pick_up()
```

Your code can read the satchel, but only `pick_up()` fills it.
