# A spell of your own

`def` gives a name to some lines. The indented lines under it are the function's **body**. Calling the name, with parentheses, runs the body:

```python run
def hop():
    knight.jump(1, 2)
    knight.jump(1, -2)

hop()
hop()
```

Defining runs nothing: `def` only teaches Python the name. This knight never moves:

```python run
def hop():
    knight.jump(1, 2)
    knight.jump(1, -2)
```

Python reads a program from the top, so a function has to be defined above the first line that calls it:

```python run error
hop()

def hop():
    knight.jump(1, 2)
```
