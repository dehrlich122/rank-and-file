# What happens in the spell

A name made inside a function lives only there. When the function ends, the name is gone:

```python run error
def toll():
    knight.jump(1, 2)
    paid = int(knight.read())

toll()
print(paid)
```

A function can read a name from outside, but it can't change one. Giving a name a value inside the function makes a new name of the function's own, so this fails too:

```python run error
total = 0

def toll():
    knight.jump(1, 2)
    total += int(knight.read())

toll()
```

So values go in through the parentheses and come out through `return`. The total stays outside. A guard hears your knight from the square beside its gate:

```python run
def toll():
    knight.jump(1, 2)
    return int(knight.read())

total = toll()
knight.jump(2, -1)
print(total)
```
