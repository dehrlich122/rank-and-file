# The examiner's round

Nothing new here: everything in this chapter, in one spell. A function takes its orders through parameters, may give one a default, keeps its own names to itself, and hands its answer back with `return`.

```python run
def hop(times=1):
    for i in range(times):
        knight.jump(1, 2)
        knight.jump(1, -2)
    return times * 2

print(hop(), hop())
```

The examiner makes every call, and wants every answer.
