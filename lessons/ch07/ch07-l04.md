# Spells that answer

`return` hands a value back to the line that called the function. The call then stands for that value: keep it in a name, print it, or do sums with it.

```python run
def double(n):
    return n * 2

knight.jump(1, 2)
rune = int(knight.read())
print(double(4), double(rune))
```

`print` only shows a value on the screen. A function with no `return` hands back `None`:

```python run
def double(n):
    print(n * 2)

answer = double(4)
print(answer)
```

`return` also ends the function right there: no line after it runs. The examiner asks for answers the same way: it calls, and takes what comes back.

```python run calls double(8)
def double(n):
    return n * 2
```
