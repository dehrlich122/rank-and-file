# Spells that take orders

A name inside the parentheses of the `def` line is a **parameter**: a blank that each call fills with a value.

```python run
def climb(times):
    for i in range(times):
        knight.jump(2, 1)
        knight.jump(-2, 1)

climb(1)
climb(2)
```

A function can have several parameters, filled in order. One with a **default value** may be left out of a call. Here an **examiner** makes the call instead of your program: it gives `way` and leaves `times` at its default.

```python run calls climb(-1)
def climb(way, times=1):
    for i in range(times):
        knight.jump(2, way)
        knight.jump(-2, way)
```

A parameter with no default has to be filled:

```python run error
def climb(times):
    for i in range(times):
        knight.jump(2, 1)
        knight.jump(-2, 1)

climb()
```
