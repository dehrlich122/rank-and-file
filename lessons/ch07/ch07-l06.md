# Spells that cast spells

A function can call another function. Here `trail()` calls `hop()` twice, with a jump of its own in between:

```python run
def hop():
    knight.jump(1, 2)
    knight.jump(1, -2)

def trail():
    hop()
    knight.jump(2, 1)
    hop()

trail()
```

At each `hop()`, Python goes into `hop`, does its two jumps, and comes back to the next line of `trail`. Small spells make bigger spells, and the program itself stays short.

With several functions it helps to say what each one does. A sentence in triple quotes right under the `def` line is a docstring. It doesn't count as a line:

```python run
def hop():
    """Two jumps: up and over, then back down."""
    knight.jump(1, 2)
    knight.jump(1, -2)

hop()
```
