# Stepping stones

Your knight can't walk: it jumps. `knight.jump(dx, dy)` moves it two squares one way and one square the other, in an L. The first number is how far right (a minus goes left), the second how far up (a minus goes down).

A jump flies over whatever lies in between. Only the square it lands on matters, and landing on an enemy takes it:

```python run
knight.jump(1, 2)
```

A jump that isn't an L is an error:

```python run error
knight.jump(1, 1)
```

And landing in a pit loses the run:

```python run lost
knight.jump(2, 1)
```
