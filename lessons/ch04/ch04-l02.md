# Look before you step

`pawn.look()` names what's on the square ahead: `"wall"`, `"pit"`, `"plank"` and so on, or `None` if the square is empty. Looking is free: it takes no tick.

```python run
print(pawn.look())
```

An `if` runs the lines indented under it only when its condition is True. Walking over a plank picks it up, and `pawn.bridge()` lays it over the pit ahead:

```python run
pawn.move(2)
if pawn.look() == "pit":
    pawn.bridge()
pawn.move(3)
```

Walk on without looking, and the pawn falls in:

```python run lost
pawn.move(3)
```
