# True or False

A question like `pawn.at_goal()` gets one of two answers: `True` or `False`. A **comparison** gets one too: `>` (more than), `<` (less than), `>=` and `<=` (or equal), `==` (equal, with two equals signs) and `!=` (not equal):

```python run
print(pawn.at_goal())
print(5 > 4, 5 < 4, 5 == 5, 5 != 5)
```

`and` is True when both sides are, `or` when either side is, and `not` turns True into False:

```python run
print(5 > 4 and 5 < 4)
print(5 > 4 or 5 < 4)
print(not 5 > 4)
```

This guard wants a True or False. Printing a comparison prints its answer:

```python run
pawn.move()
print(5 < 4)
print(5 > 4)
pawn.move(2)
```
