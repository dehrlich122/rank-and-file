# Choices in a loop

An `if` inside a loop runs again every round, and its condition is asked again too. So the same lines can do something different each time:

```python run
for number in range(4):
    if number % 2 == 0:
        print(number, "is even")
    else:
        print(number, "is odd")
```

The rooks here never move, but the pawn does: every round, it has to look again.
