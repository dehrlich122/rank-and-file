# Elif

`elif` (short for "else if") adds more conditions to a chain. Python checks them from the top and runs only the first branch whose condition is True. `else` catches whatever is left.

Here a loop looks ahead, then to the right, then behind:

```python run
for side in range(3):
    if pawn.look() == "pit":
        print("A pit!")
    elif pawn.look() == "wall":
        print("A wall.")
    else:
        print("Nothing there.")
    pawn.turn_right()
```
