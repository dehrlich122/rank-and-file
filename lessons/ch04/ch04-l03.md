# One thing or the other

`else` gives an `if` a second branch: its lines run when the condition is False.

`look()` gives back `None` for an empty square. In an `if`, `None` counts as False and any word counts as True, so `if pawn.look():` asks "is anything there?". `not` turns the answer round:

```python run
if pawn.look():
    print("Something is in the way.")
else:
    print("The way is clear.")
print(not pawn.look())
```

Turn to face the open side, and the same lines say the opposite:

```python run
pawn.turn_right()
if pawn.look():
    print("Something is in the way.")
else:
    print("The way is clear.")
print(not pawn.look())
```
