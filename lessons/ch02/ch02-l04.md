# Values inside text

An **f-string** is text with values inside it. Put an `f` before the quotes, and Python works out anything in curly braces and puts it into the text:

```python run
gems = 3
print(f"I have {gems} gems")
print(f"Twice that is {gems * 2}")
```

A guard who asks a question wants the answer exactly as asked, word for word, printed from right next to the gate. This one asks for a sum. A wrong answer only gets a reply, and the right one opens the gate:
