# Remainders and timing

`%` gives the **remainder** after dividing: `7 % 4` is `3`, because 4 goes into 7 once with 3 left over. Remainders go round and round, like a clock:

```python run
print(4 % 4, 5 % 4, 6 % 4, 7 % 4, 8 % 4)
```

A timed gate keeps time the same way. This one is open for 2 ticks of every 4, starting open, and its badge counts the ticks. Every square moved and every tick waited counts, and `pawn.wait(3)` waits three. Arrive just as it shuts, and you're crushed:

```python run lost
pawn.move(2)
```

Arrive just as it opens, and you're through before it shuts:

```python run
pawn.wait(3)
pawn.move(3)
```
