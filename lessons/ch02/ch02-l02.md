# Doing the sums

Python does arithmetic anywhere a number can go, even inside a call's brackets. `+` adds, `-` subtracts and `*` multiplies:

```python run
print(5 + 3, 5 - 3, 5 * 3)
print(2 + 3 * 4)
```

As in maths, `*` comes before `+`, so the second line prints 14. Brackets change the order: `(2 + 3) * 4` is 20.

Names work in sums too, and Python works out the sum before the pawn moves:

```python run
side = 1
pawn.move(side * 3)
pawn.turn_left()
pawn.move(side + 1)
```
