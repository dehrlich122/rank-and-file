# Counting, then the sums

Some functions **give back** a value. `pawn.squares_ahead()` counts the squares your pawn could walk before something stops it, and gives back that number. Store it in a name, then do sums with it: `+` adds, `-` takes away and `*` multiplies:

```python run
ahead = pawn.squares_ahead()
print(ahead, ahead + 1, ahead - 1, ahead * 2)
pawn.move(ahead - 1)
```

Counting is free: it doesn't move your pawn or take a tick.

As in maths, `*` comes before `+`, and brackets change the order:

```python run
print(2 + 3 * 4, (2 + 3) * 4)
```
