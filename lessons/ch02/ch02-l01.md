# Names for numbers

A **variable** is a name for a value. `=` stores the value under the name, and from then on the name stands for it:

```python run
steps = 2
pawn.move(steps)
pawn.turn_right()
pawn.move(steps)
```

Change the first line to `steps = 1` and run it again: both moves change with it. That's why programmers name their numbers. When a number changes, it changes in one place.

A name has to be spelled the same way every time. Python stops at a name it doesn't know:

```python run error

```
