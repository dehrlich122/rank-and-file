# Counting squares

Some functions **give back** a value. `pawn.squares_ahead()` counts the squares your pawn could walk before something stops it, and gives back that number. Print it, or store it in a name:

```python run
print(pawn.squares_ahead())
ahead = pawn.squares_ahead()
pawn.move(ahead)
```

Counting is free: it doesn't move your pawn or take a tick.

`/` divides exactly, with a decimal point: `7 / 2` is `3.5`. Squares only come whole, so there's `//`, which divides and drops what's left over: `7 // 2` is `3`. `move()` won't take a number with a decimal point:

```python run error
pawn.move(7 / 2)
```
