# Halving

`/` divides exactly, with a decimal point: `7 / 2` is `3.5`. Squares only come whole, so Python has `//`, which divides and drops what's left over:

```python run
print(7 / 2, 7 // 2, 8 // 2)
```

`move()` won't take a number with a decimal point, even one that looks whole, like `4.0`:

```python run error
pawn.move(8 / 2)
```
