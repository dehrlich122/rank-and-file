# Loops inside loops

A loop's indented lines can hold another loop. The inner loop then runs all the way through on every round of the outer one:

```python run
for row in range(2):
    for seat in range(3):
        print("Row", row, "seat", seat)
```

Two laps round the pillar, each lap four sides. The outer loop counts laps, the inner loop counts sides, and the indentation shows which lines belong to which:

```python run
for lap in range(2):
    print("Lap", lap)
    for side in range(4):
        pawn.move(2)
        pawn.turn_right()
```
