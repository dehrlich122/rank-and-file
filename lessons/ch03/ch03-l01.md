# Loops

A `for` loop repeats the lines indented under it. `range(3)` hands the loop the numbers 0, 1 and 2, one per round, so the loop runs three times. Each round, `step` holds that round's number:

```python run
for step in range(3):
    print("Step", step)
```

The indented lines can be moves and turns too, and they repeat as a block. Four rounds of "walk two, turn right" take the pawn all the way round the pillar:

```python run
for side in range(4):
    pawn.move(2)
    pawn.turn_right()
```

Python knows which lines belong to the loop by their indentation: 4 spaces. A loop with nothing indented under it is an error:

```python run error
for step in range(3):
pawn.move()
```
