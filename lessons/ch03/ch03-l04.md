# Clockwork

A patrol with a gear badge is **clockwork**: your code winds it, not your moves. It takes one step each time a line of your code runs *for the first time*. A line that runs again, in a loop, doesn't wind it. Its gear counts its steps.

Here the loop is two lines, so the patrol takes two steps, then stands still while the pawn walks three squares:

```python run
for step in range(3):
    pawn.move()
```

The same three moves copied out are three new lines, three steps, and the patrol catches the pawn:

```python run lost
pawn.move()  # a new line
pawn.move()  # another new line
pawn.move()  # and another
```
