# The loop's number

The loop's variable holds each round's number, and your code can use it. `range` can start anywhere, and a third number is the step from one number to the next. A negative step counts down:

```python run
for number in range(5, 0, -1):
    print(number)
```

These steps cross a bottomless pit, each one square longer than the last. Step off the walkway and you fall. Here `length` is 1, then 2, then 3:

```python run
for length in range(1, 4):
    pawn.move()
    pawn.turn_right()
    pawn.move(length)
    pawn.turn_left()
```

The same steps at a fixed length, and the pawn falls in:

```python run lost
for length in range(1, 4):
    pawn.move()
    pawn.turn_right()
    pawn.move(2)
    pawn.turn_left()
```
