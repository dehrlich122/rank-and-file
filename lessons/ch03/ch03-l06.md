# Loops that grow

The inner loop's `range()` can use the outer loop's number. Then each round of the outer loop repeats the inner lines a different number of times:

```python run
for row in range(1, 4):
    for seat in range(row):
        print("Row", row, "seat", seat)
```

Row 1 has one seat, row 2 has two, and row 3 has three.

The sentry here is clockwork, like the one on the stairs: only a line running for the first time winds it.
