# A fresh answer every round

Each round, the loop runs its lines again from the top. So a question asked inside the loop is asked again every round, and the answer can change. This corridor turns right at every corner, and each stretch is shorter than the last:

```python run
for corner in range(3):
    print(pawn.squares_ahead())
    pawn.move(pawn.squares_ahead())
    pawn.turn_right()
```

A number typed into the loop is the same every round, so it fits only one stretch:

```python run error
for corner in range(3):
    pawn.move(3)
    pawn.turn_right()
```
