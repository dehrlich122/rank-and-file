# The written route

This brings the chapter together. A `for` loop can go through the pieces of a split text one at a time. Inside it, a piece's first character is `piece[0]`, and `piece[1:]` is everything after it.

```python run
pawn.move()
for piece in pawn.read().split(","):
    print(piece[0], int(piece[1:]))
```

Text often hides more than one fact in a line, like a turn and a distance. Cut it into pieces, then ask each piece questions with `in`, `find()` and `count()`.
