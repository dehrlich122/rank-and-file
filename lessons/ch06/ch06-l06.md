# The written route

This brings the chapter together. `split(",")` gives back a list: the pieces, in square brackets. A later chapter covers lists properly. For now, a list is a row of items you can pick from by position, like `pieces[0]`.

```python run
pawn.move()
print(pawn.read().split(","))
```

A `for` loop can go through a list one item at a time, so the loop runs once for each piece, however many there are:

```python run
pawn.move()
for piece in pawn.read().split(","):
    print(piece)
```

Inside the loop, a piece's first character is `piece[0]`, and `piece[1:]` is everything after it:

```python run
pawn.move()
for piece in pawn.read().split(","):
    print(piece[0], int(piece[1:]))
```
