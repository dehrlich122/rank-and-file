# Where the rune points

`int()` turns text made of digits into a number: `int("12")` is 12, which you can walk. `split(",")` cuts a text into pieces wherever the comma is, and gives them back as a list (the pieces in square brackets). Pick a piece by its position: `pieces[0]` is the first, `pieces[1]` the second.

```python run
pawn.move()
pieces = pawn.read().split(",")
print(pieces)
print(int(pieces[1]) + 1)
```

A piece is still text until `int()` has turned it into a number, and walking needs a number:

```python run error
pawn.move()
pieces = pawn.read().split(",")
pawn.move(pieces[0])
```
