# The runestone

A rune is a stone with text on it. Walk onto it, and `pawn.read()` gives back what it says. Keep that text in a variable and you can use it later, even after you've walked on.

```python run
pawn.move()
saying = pawn.read()
print(saying)
print(saying[0])
```

Text counts its characters from 0, so `saying[0]` is the first one. Away from a rune, `read()` gives back `None`, which has no characters to pick:

```python run error
print(pawn.read()[0])
```
