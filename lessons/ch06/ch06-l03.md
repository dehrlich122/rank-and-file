# Smudged runes

A method is something a text can do, called with a dot. It never changes the text: it gives back a new one. `strip()` removes the spaces at both ends, `upper()` makes capitals, `lower()` makes small letters, and `replace(old, new)` swaps every `old` for `new`.

```python run
pawn.move()
text = pawn.read()
print(text.strip())
print(text.upper())
print(text.replace("-", " "))
```

Each method gives back a text, so another can follow it:

```python run
pawn.move()
print(pawn.read().strip().lower())
```

A text can't be changed in place, only copied:

```python run error
pawn.move()
text = pawn.read()
text[0] = "X"
```
