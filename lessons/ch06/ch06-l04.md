# Which road?

`in` asks whether one text appears inside another, and answers True or False, so an `if` can use it. Four methods ask other questions: `startswith()` and `endswith()` check the two ends, `find()` gives the position where a piece starts (-1 if it isn't there), and `count()` says how many times it appears.

```python run
pawn.move()
text = pawn.read()
print("pit" in text, text.startswith("A"), text.endswith("!"))
print(text.find("pit"), text.count("i"))
if "pit" in text:
    pawn.turn_right()
pawn.move()
```
