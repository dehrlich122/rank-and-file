# Cut it out

A slice cuts a stretch out of a text. `text[start:stop]` begins at `start` and stops just before `stop`. Leave one out to go as far as that end, and a minus counts back from the end. `len(text)` says how many characters there are.

```python run
pawn.move()
text = pawn.read()
print(text[5:])
print(text[:4])
print(text[-3:])
print(len(text))
```

Asking for one position past the end is an error:

```python run error
pawn.move()
print(pawn.read()[40])
```
