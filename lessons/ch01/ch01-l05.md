# Plan, then code

This level uses everything from the chapter: calling functions, arguments, and putting instructions in the right order.

Long routes are easier if you plan them first. Break the path into straight pieces, then write one line for each straight and one for each turn. Writing the plan as comments first is a habit real programmers use:

```python run
# first straight: 2 squares
pawn.move(2)
# corner
pawn.turn_left()
# second straight: 2 squares
pawn.move(2)
```

If the pawn goes astray, don't guess. Use the step buttons under the board to walk through your program one line at a time, and find the exact line where the plan and the pawn disagree.
