# Calling a function

Your pawn understands commands called **functions**. To use one, you *call* it: write its name, then a pair of parentheses.

```python run
pawn.move()
```

Press **Run** on the example and watch the pawn take one step forward.

`pawn.move()` reads as "pawn, do your *move*". The dot connects the pawn to one of its abilities, and the parentheses `()` make it happen. Without them, Python just looks at the ability and does nothing.

Python runs your lines from top to bottom, one at a time:

```python run
pawn.move()
pawn.move()
```

These examples are editable. Add a line, or break one on purpose and see what Python says.
