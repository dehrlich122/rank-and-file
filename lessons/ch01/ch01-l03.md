# Turning, and why order matters

Your pawn has learned two new abilities: `pawn.turn_left()` and `pawn.turn_right()`. Each one turns the pawn a quarter turn **without moving it**.

Python runs your program **in order**, top to bottom. These two programs contain the same three lines, in a different order. Run both and compare where the pawn ends up:

```python run
pawn.move()
pawn.turn_right()
pawn.move()
```

```python run
pawn.turn_right()
pawn.move()
pawn.move()
```

Same instructions, different journey. Before you write a route, plan it: which way, how far, and where it turns.
