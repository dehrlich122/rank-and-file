# Arguments

Some functions accept extra information inside their parentheses. That information is called an **argument**.

`pawn.move()` takes one step. Give it a number and it takes that many:

```python run
pawn.move(3)
```

An argument is like the detail in an order: *move*, but *how far?* Without one, `move` uses its default of 1 step.

Numbers don't need quote marks. `pawn.move(3)` is the number three, but `pawn.move("3")` is text, and the pawn can't walk a piece of text. Try it and read what happens:

```python run error
pawn.move("3")
```
