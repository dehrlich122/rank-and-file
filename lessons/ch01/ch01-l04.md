# Talking: print() and comments

`print()` is a function too. It shows whatever you give it in the **console** under the editor. Text goes in quote marks:

```python run
print("Hello, board!")
pawn.move()
print("One step done")
```

Text in quotes is called a **string**. The quotes tell Python "this is text, not a name". Without them, Python would go looking for something called `Hello`.

A **comment** starts with `#`. Python skips everything from the `#` to the end of the line. Comments are notes for humans, including you next week:

```python run
# Head for the far side
pawn.move(2)  # up the middle
```

Good comments explain *why*, not just *what*.
