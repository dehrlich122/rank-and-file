# Rounds you can't count

A `for` loop has to know how many times to go round. A `while` loop doesn't: it repeats for as long as anything you can ask is True. Here the pawn walks until something is in the way. At the edge of the board `look()` says `"edge"`:

```python run
while not pawn.look():
    pawn.move()
```

A fixed count can't adapt to the hall. This one walks five squares whatever is there:

```python run error
for step in range(5):
    pawn.move()
```
