# Leave early

`break` leaves the nearest loop at once. A `while True:` loop never ends by itself, so a `break` inside it decides when. This one leaves as soon as the pawn sees a wall:

```python run
while True:
    pawn.move()
    if pawn.look() == "wall":
        break
```

`continue` is different. It skips the rest of this pass and goes on with the next one:

```python run
for step in range(6):
    if pawn.look() == "wall":
        continue
    pawn.move()
```
