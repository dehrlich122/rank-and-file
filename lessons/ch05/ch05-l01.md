# Until you arrive

A `while` loop repeats the lines indented under it for as long as its condition is True. The condition is checked before every pass, so the loop stops the moment it turns False, however many passes that took.

```python run
while not pawn.at_goal():  # asked again before every step
    pawn.move()  # one step
```

A condition that never turns False never lets go. The run stops itself, and says why:

```python run timeout
while True:
    pawn.wait()
```
