# Keeping count

A counter is a variable that changes on every pass of a loop. Set it before the loop, then add to it inside:

```python run
steps = 0
while steps < 3:
    steps += 1
print(steps)
```

Python has to know the counter before it can add to it. Skip the first line, and it stops:

```python run error
while steps < 3:
    steps += 1
```
