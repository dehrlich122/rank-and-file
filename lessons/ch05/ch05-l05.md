# Take them all

A `while` loop asks the board before every pass, so it goes round as many times as the board says: five times, once, or not at all. Here a rook stands diagonally ahead, again and again:

```python run
while pawn.look("right") == "rook":
    pawn.capture_right()
```

Taking a rook ends its attacks. Walk past one instead, and it takes the pawn:

```python run lost
pawn.move()
```
